Student Guide: Cycling Physics in Excel

How to translate the Python functions into Excel cell formulas
Important: Excel cannot call these Python functions directly unless Python is connected to Excel. This guide shows the equivalent Excel formulas so students can use the same ideas in spreadsheets.
1. Frontal Area Demo

demonstrateCdA

Uses height and aero position to estimate CdA.

InputsUnits
Heightcm
Aero factorunitless
OutputUnits
CdAm²

Python idea:

CdA = 0.63 × (aero_factor × 0.00155 × height_cm)

Excel formula:

=0.63*(B2*0.00155*A2)

If A2 = height in cm and B2 = aero factor.

2. Rolling Resistance + Gravity

calculate_rolling_resistance_and_gravity_force

Calculates the rolling resistance force and the gravity force on a slope.

InputsUnits
Total masskg
Slope%
OutputsUnits
Rolling resistance forceN
Gravity forceN

Excel formulas:

theta = ATAN(B2/100)
F_roll = 0.004 * A2 * 9.81 * COS(theta)
F_gravity = A2 * 9.81 * SIN(theta)

Direct Excel versions:

=0.004*A2*9.81*COS(ATAN(B2/100))
=A2*9.81*SIN(ATAN(B2/100))

If A2 = total mass in kg and B2 = slope %.

3. Frontal Area

calculate_frontal_area

Estimates the rider’s frontal area from height and riding position.

InputsUnits
Heightcm
Aero factorunitless
OutputUnits
Frontal aream²

Excel formula:

=B2*0.00155*A2

If A2 = height in cm and B2 = aero factor.

4. Power from Speed

calculate_power_from_velocity

Calculates watts needed to hold a speed on flat ground, climbs, or descents.

InputsUnits
Velocitykm/h
Heightcm
Total masskg
Slope%
Aero factorunitless
OutputUnits
PowerW

Python idea:

power = speed × (aero force + rolling force + gravity force)

Excel formula:

=IF(((0.5*1.225*0.63*(B2*0.00155*C2)*(A2/3.6)^2)
+ (0.004*D2*9.81*COS(ATAN(E2/100)))
+ (D2*9.81*SIN(ATAN(E2/100))))
* (A2/3.6) <= 0, 0,
((0.5*1.225*0.63*(B2*0.00155*C2)*(A2/3.6)^2)
+ (0.004*D2*9.81*COS(ATAN(E2/100)))
+ (D2*9.81*SIN(ATAN(E2/100))))
* (A2/3.6))

If that looks too long, break it into helper cells:

  • velocity_mps = A2/3.6
  • frontal_area = B2*0.00155*C2
  • F_aero = 0.5*1.225*0.63*frontal_area*velocity_mps^2
  • F_roll = 0.004*D2*9.81*COS(ATAN(E2/100))
  • F_gravity = D2*9.81*SIN(ATAN(E2/100))
  • Power = MAX(0,(F_aero+F_roll+F_gravity)*velocity_mps)

5. Watts from Speed

calculate_watts_from_speed

A simpler version that adds bike weight before calculating watts.

InputsUnits
Speedkm/h
Rider weightkg
Rider heightcm
Slope%
OutputUnits
WattsW

Use bike weight = 8.0 kg.

Excel formula:

=IF(((0.5*1.225*0.63*(B2*0.00155*C2)*(A2/3.6)^2)
+ (0.004*(D2+8)*9.81*COS(ATAN(E2/100)))
+ ((D2+8)*9.81*SIN(ATAN(E2/100))))
* (A2/3.6) <= 0, 0,
((0.5*1.225*0.63*(B2*0.00155*C2)*(A2/3.6)^2)
+ (0.004*(D2+8)*9.81*COS(ATAN(E2/100)))
+ ((D2+8)*9.81*SIN(ATAN(E2/100))))
* (A2/3.6))

If A2 = speed, B2 = height, D2 = rider weight, and E2 = slope.

6. Paceline Draft Ratio

calculate_drag_ratio_in_paceline

Returns a unitless draft factor based on a rider’s position in a group.

InputUnits
Position in paceline1-based index
OutputUnits
Power ratiounitless

Power curve values:

{400, 309, 277, 268, 261, 255, 250, 245}

Excel formula:

=IF(AND(A2>=1,A2<=8),CHOOSE(A2,400,309,277,268,261,255,250,245)/400,245/400)

This gives:
1.0000, 0.7725, 0.6925, 0.6700, 0.6525, 0.6375, 0.6250, 0.6125

Suggested spreadsheet layout

Cell Meaning
A2Speed or height or position, depending on the formula
B2Aero factor or another input value
C2Height or another input value
D2Mass or rider weight
E2Slope %

Best practice: rename cells with labels like Height_cm, Speed_kph, and Slope_pc so the formulas are easier to read.
