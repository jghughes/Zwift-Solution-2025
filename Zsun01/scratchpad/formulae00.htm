Cycling Physics Formulae

A student-friendly guide to the main riding physics functions in jgh_formulae00.py
Excel note: These are the ideas behind the formulas. Excel does not run Python functions directly unless a special setup is used. This page explains what each function means, what goes in, and what comes out.
1. Frontal Area / CdA Demo

demonstrateCdA

Estimates a rider’s aerodynamic size from height and riding position.

InputsUnits
Heightcm
Aero position factorunitless
OutputUnits
CdAm²
CdA = Cd × frontal area
2. Rolling + Gravity Forces

calculate_rolling_resistance_and_gravity_force

Calculates the two main road forces caused by tire contact and slope.

InputsUnits
Total masskg
Slope%
OutputsUnits
Rolling resistance forceN
Gravity forceN
F_roll and F_gravity
3. Frontal Area Estimate

calculate_frontal_area

Estimates the rider’s front-facing area using height and aero position.

InputsUnits
Heightcm
Aero factorunitless
OutputUnits
Frontal aream²
A = aero_factor × (0.00155 × height_cm)
4. Power from Speed

calculate_power_from_velocity

Calculates the watts needed to hold a target speed on a given slope.

InputsUnits
Velocitykm/h
Heightcm
Total masskg
Slope%
Aero factorunitless
OutputUnits
PowerW
P = speed × (aero + rolling + gravity)
5. Watts from Speed

calculate_watts_from_speed

A simpler wrapper that adds bike weight and then calculates watts.

InputsUnits
Speedkm/h
Rider weightkg
Rider heightcm
Slope%
OutputUnits
WattsW
watts = power needed at that speed
6. Paceline Draft Ratio

calculate_drag_ratio_in_paceline

Returns a draft factor based on rider position in a group.

InputUnits
Position in paceline1-based index
OutputUnits
Power ratiounitless
1.0 = front rider, smaller values = more draft

Quick summary

Function What it does
demonstrateCdA Estimates aerodynamic size from rider height and position.
calculate_rolling_resistance_and_gravity_force Computes the forces caused by tires and hills.
calculate_frontal_area Estimates the rider’s frontal area.
calculate_power_from_velocity Computes the watts needed to hold a speed.
calculate_watts_from_speed Convenience version that includes bike weight.
calculate_drag_ratio_in_paceline Shows how draft changes by position in a group.
